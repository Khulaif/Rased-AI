# راصد - Rased

## 🎯 نظام ذكي للكشف عن الاحتيال في الخدمات الحكومية

**راصد** هو محرك أمني تنبؤي يعمل داخل منصة أبشر لتحليل سلوك المستخدم والعمليات بشكل لحظي، واكتشاف أي نمط غير طبيعي يشير لاحتمال الاحتيال أو الانتحال أو الاختراق **قبل وقوع الضرر**.

---

## 💡 الفكرة الأساسية

> نظام ذكاء اصطناعي يتحقق من سلامة المعاملات في أبشر لحظياً، يكشف السلوك الشاذ، يمنع الاحتيال قبل حدوثه، ويطبق حماية ذكية بناءً على درجة المخاطر.

### المبدأ
- **LSTM Model**: نموذج شبكة عصبية يتعلم سلوك كل مستخدم بشكل فردي
- **Digital Twin (توأم رقمي)**: نسخة رقمية من نمط سلوك كل مستخدم
- **أي اختلاف بالسلوك** → حساب درجة خطورة → اتخاذ قرار

### الميزة الرئيسية
✅ **يعمل بالخلفية** - لا يلمس تجربة المستخدم إطلاقاً

## 🔍 كيف يعمل النظام؟

### 1️⃣ جمع البيانات
عند كل عملية في أبشر، يجمع النظام:
- **الموقع**: إحداثيات GPS، IP، دولة
- **الجهاز**: نوع الجهاز، نظام التشغيل، بصمة الجهاز
- **الوقت**: ساعة الدخول، يوم الأسبوع
- **السلوك**: سرعة التنقل، تسلسل العمليات

### 2️⃣ التنبؤ (LSTM)
- النموذج يتنبأ بالإجراء التالي المتوقع
- إذا كان الإجراء الفعلي مختلف جداً → علامة شذوذ

### 3️⃣ المقارنة (Digital Twin)
- مقارنة السلوك الحالي مع التوأم الرقمي
- حساب نسبة الانحراف لكل عامل

### 4️⃣ تقييم المخاطر
| العامل | الوزن |
|--------|-------|
| تنبؤ LSTM | 30% |
| الموقع الجغرافي | 30% |
| بصمة الجهاز | 20% |
| سرعة التنقل | 20% |

### 5️⃣ اتخاذ القرار
- **سماح**: العملية تمر بشكل طبيعي
- **تحقق**: طلب OTP أو Face ID أو نفاذ
- **حظر**: إيقاف فوري + تنبيه SOC

## 🎯 حالات الاستخدام

| السيناريو | الكشف | الإجراء |
|-----------|-------|---------|
| نقل ملكية سيارة من موقع غريب | VPN/موقع جديد | تحقق إضافي |
| تنقل سريع جداً (Bot) | سرعة غير بشرية | حظر فوري |
| جهاز جديد + عملية حساسة | تغير بصمة الجهاز | تحقق إضافي |
| سلوك طبيعي من المستخدم | لا انحراف | سماح |
